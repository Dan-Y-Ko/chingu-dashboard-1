# Chingu Dashboard

The Chingu Dashboard is an internal web platform designed to streamline
the onboarding and project experience for members of the Chingu community.

## Project Overview

Chingu is a community where developers are matched into teams to collaborate
on software projects over a defined development period. For more info checkout:
https://www.chingu.io/

The first phase of the Dashboard focused on improving the onboarding experience
for new members and providing a central platform for managing their participation
in Chingu projects.

## Status

This project reached an internal alpha and was deployed to a Vercel production
environment for internal testing. It was not released publicly.

Current Status: Terminated
